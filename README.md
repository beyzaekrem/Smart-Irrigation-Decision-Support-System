# Smart Irrigation Decision Support System

A data-driven decision support system designed to optimize irrigation planning using environmental parameters and predictive modeling.

## Overview

This project aims to support sustainable agriculture by providing intelligent irrigation recommendations based on environmental data. The system analyzes soil moisture, temperature, humidity, and other parameters to determine optimal irrigation timing and quantity.

The main objective is to reduce water waste, improve crop health, and assist decision-makers with data-backed insights.

## Motivation

Water scarcity and inefficient irrigation are major global challenges. Traditional irrigation methods often rely on fixed schedules rather than real-time environmental conditions.

This system demonstrates how computational modeling and data analysis can support smarter agricultural decisions.

## Features

- Environmental parameter input (soil moisture, temperature, humidity, etc.)
- Decision support output for irrigation timing
- Modular system structure
- Data modeling and analysis logic
- Scalable architecture for future sensor integration

## System Architecture

The system consists of:

1. Data Input Layer  
   Collects environmental variables.

2. Processing Layer  
   Applies rule-based logic and modeling techniques.

3. Decision Layer  
   Generates irrigation recommendations.

4. Interface Layer  
   Provides a user-friendly interaction environment (Streamlit-based UI).

## Technologies Used

- Python
- Streamlit
- Data Processing Libraries (Pandas, NumPy)
- Basic Predictive Modeling Techniques

## How to Run

1. Clone the repository:

git clone https://github.com/beyzaekrem/Smart-Irrigation-Decision-Support-System.git


2. Navigate into the project directory:

cd Smart-Irrigation-Decision-Support-System


3. Install dependencies:

pip install -r requirements.txt


4. Run the application:

python -m streamlit run app.py
